# ToxicFox

A standalone, browser-based fox locomotion field test. It isolates Gecko Escape’s current experimental fox, its canvas renderer, and its movement controller in a dependency-free test project. No Gecko Escape characters, levels, or external assets are required.

## Controls

- Walk/run: A/D or left/right arrows
- Jump: Space or Up
- Investigate: hold I while still

The flat test area includes low steps and platforms for checking stride, turning, jumps, and landings. The existing fox design and movement are the baseline; this project adds no locomotion overhaul or larger game content.
